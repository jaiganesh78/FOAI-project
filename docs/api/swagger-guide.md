# Swagger & OpenAPI Guide — GPIOS

## Overview
OpenAPI 3.0 documentation is auto-generated by NestJS and accessible at `/api/docs`.

## Key Features
- **Grouping**: Endpoints are grouped by domain tags (`Health`, `Policy`, `Citizen`, `Eligibility`, `AI`, etc.).
- **Versioning**: API URI versioning is enforced (`/api/v1/...`).
- **Security Placeholders**: Bearer JWT authentication security scheme is configured in OpenAPI spec.
