# Document Classification Engine Specification

Pre-OCR classification stage detecting:
- Document Type (Identity Proof, Income Certificate, Land Record, Bank Passbook)
- Detected Language (default `en`)
- Page Orientation (`PORTRAIT`, `LANDSCAPE`)
- Layout Type (`SINGLE_PAGE`, `MULTI_PAGE`, `FORM`, `TABULAR`)
- Password Protection & Encryption
- Automatic OCR Template Selection (`ocrTemplateId`)
