# Document Quality Assessment Engine Specification

Pre-OCR quality checks calculating:
- Resolution DPI (e.g. 300 DPI)
- Blur & Noise detection
- Contrast & Brightness scoring
- Quality Score (0 - 100)
- Quality Grade (`EXCELLENT`, `GOOD`, `FAIR`, `POOR`, `UNUSABLE`)
- OCR Readiness (`READY`, `NEEDS_PREPROCESSING`, `UNUSABLE`, `SKIPPED`)
- Issues & Recommended Fixes
