# Onboarding Discovery Future Roadmap

## Sprint 4+: AI-Driven Dynamic Question Generation
- Integrate LLM Provider (`LLM_PROVIDER`) to generate adaptive clarifying questions for incomplete or ambiguous citizen profiles.
- Voice-assisted question delivery in regional languages.

## Sprint 4+: OCR & Document Verification Integration
- Add document upload question component type (`FILE_UPLOAD`).
- Auto-extract facts from uploaded documents (Aadhaar, PAN, Ration Card, Land Records) via OCR and set confidence sources to `DOCUMENT`.

## Sprint 5+: Collaborative Onboarding & Multi-Persona Blueprints
- Support agent-assisted onboarding (e.g. Gram Panchayat operators completing onboarding on behalf of citizens).
- Blueprint migration engine executing active session upgrades.
