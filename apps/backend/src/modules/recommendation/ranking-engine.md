# Multi-Stage Ranking Engine Architecture

## Multi-Stage Pipeline
1. **Benefit Score**: Monetary & long-term economic value.
2. **Urgency Score**: Application deadlines & seasonal urgency.
3. **Application Readiness**: Document verification completeness.
4. **Citizen Preference Match**: Alignment with preferred scheme categories.
5. **Utility Score Computation**: Final composite utility score normalized to 0–100.
