# Personalized Action Planning Engine Architecture

## Overview
Transforms ordered journey steps into actionable daily citizen instructions:
- **`TODAY`**: Immediate priority steps (e.g. Aadhaar verification).
- **`TOMORROW`**: Dependent next steps (e.g. Land record Patta collection).
- **`NEXT_UP`**: Secondary tasks (e.g. Bank passbook upload).
- **`FINALLY`**: Final application submission and receipt tracking.
